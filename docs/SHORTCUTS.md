| Ctrl+Tab | Sonraki sekme |
| Ctrl+R | Yenile |
| Ctrl+K | Komut paleti |
| Ctrl+Shift+A | AI paneli ac/kapat |
| Ctrl+D | Yer imi ekle |
| Ctrl+L | Adres cubugu |
| Ctrl+F | Sayfada ara |
| F11 | Tam ekran |
| F12 | Gelistirici araclari |
